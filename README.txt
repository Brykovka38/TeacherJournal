ЭТАП 6 — ИСТОРИЯ ЗАНЯТИЙ

1. Сделайте резервную копию базы teacher_journal через pgAdmin (Backup) и папки проекта.
2. Остановите сервер Ctrl+C.
3. Скопируйте main.py, папки templates и static из архива в текущую папку TeacherJournal с заменой файлов.
4. НЕ заменяйте .env и НЕ запускайте schema.sql повторно.
5. Запустите: python -m uvicorn main:app --reload
6. Откройте http://127.0.0.1:8000/history

Фильтры: даты, группа, ученик. Исправление темы/часов/комментария — через ссылку «Изменить запись» (открывает журнал на нужную дату). Изменение даты переносит ВСЕ занятие группы; если на целевую дату уже есть занятие группы, перенос блокируется. При отработках дата пропуска не может стать позже даты отработки. Удаление записи с отработками запрещено.

ВНИМАНИЕ: изменение даты всей группы не предназначено для переноса занятия одного ученика. При удалении ошибочной записи без отработок удаление окончательное.
